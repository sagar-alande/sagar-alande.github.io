Title

Inside a Neural Network · Ten Experiments in the TensorFlow Playground

Objective

Interact with a live neural network and see how its parts change the result. I wanted real evidence for each of the six components (layers, neurons, weights, activation functions, loss functions, and optimizers) before explaining them in my visual presentation.

What is it?

A set of ten controlled experiments. I started from one baseline network, changed one setting per run, and recorded the test loss, the training loss, and a screenshot. Pairs of runs that differ in one setting show the effect of that setting alone.

Value

This artifact shows that I learn by testing, not only by reading. I designed fair experiments, kept careful records, and turned surprising results into clear explanations.

The lessons carry straight into my work in financial services, where most data is tabular, such as collateral and margin records.

Start simpleTry a small model first and add layers only when the data needs them
Choose featuresStrong inputs can beat a bigger network, as run 5b showed
Read both lossesCheck training and test loss together before trusting a model
Tune with careA learning rate that is too high can ruin a model that already works

Reflection · What I Learned

Before this activity, I assumed more layers always meant a smarter model. Now I see hidden layers as a way for the network to build useful features on its own, which it does not need to do when I provide them.

  • Each neuron draws one straight cut, and hidden layers combine those cuts into curves.
  • Good features can do the work of hidden layers. Squared inputs let a model with no hidden layers draw a perfect circle.
  • Training loss and test loss tell different stories. A large gap means memorizing, and two high losses mean the classes overlap.
  • The learning rate decides whether training works at all. The same network learned the spiral at 0.03 and collapsed at 3.
  • Harder data needs more capacity. The spiral failed with the baseline network and was learned with three layers and seven features.
  • Experiment design. Changing one setting per run so every comparison is fair.
  • Careful records. Logging epochs, both losses, and a screenshot for every run.
  • Reading model behavior. Using the gap between two loss numbers to tell overfitting from overlapping data.
  • Honest reporting. Keeping my run 5 mistake and labeling run 7, which changed two settings at once.
  • Visual explanation. Turning raw results into a presentation that zooms into each component.
  • Week 1, decision trees. A single neuron behaves like one tree split, since both draw one straight cut. The noise 25 run showed the same overfitting that tree depth limits are meant to control.
  • Week 2, word embeddings. Word2Vec is itself a small neural network, and the embedding vectors I explored are its learned weights. The same loop of prediction, loss, and weight updates created them.

“Good features can matter as much as a bigger network. My best run used no hidden layers at all.”
