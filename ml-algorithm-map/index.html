How they connect across the map

3Decision Tree→4Random Forest

A forest is many trees voting together, which cuts the overfitting of a single tree.

8RNN→9Transformer

Attention replaced step by step reading for most language tasks.

6KNNvs.10K-means

Both measure distance between points, but only KNN uses labels to make a prediction.

2Logistic Regressionvs.5SVM

Both draw a boundary between classes. SVM pushes for the widest possible gap.

7CNN→12GAN

Image GANs are usually built from CNN layers to create and judge images.

11PCA→other models

Often runs first to shrink many features before another model trains.

#AlgorithmTypeTabularVisionNLPGen AIHow it worksExample uses
1Linear RegressionSupervisedFits the straight line that keeps predicted numbers closest to the actual values.House prices, sales forecasts
2Logistic RegressionSupervisedTurns a weighted sum of features into a yes or no probability using an S-shaped curve.Credit default risk, spam filtering
3Decision TreeSupervisedAsks a chain of yes or no questions, each chosen to make the groups more pure.Loan approval, fruit sorting
4Random ForestSupervisedTrains many decision trees on random samples of the data and lets them vote.Fraud detection, customer churn
5Support Vector MachineSupervisedDraws the boundary that leaves the widest possible gap between classes.Text categorization, handwritten digits
6K Nearest NeighborsSupervisedLabels a new point by a majority vote of its k closest labeled neighbors.Product recommendations, image matching
7Convolutional Neural NetworkSupervisedSlides small filters over an image to find edges, then shapes, then whole objects.Medical image screening, pedestrian detection
8RNN and LSTMSupervisedReads a sequence one step at a time while carrying a memory of earlier steps forward.Speech recognition, next word prediction
9TransformerSelf-supervisedUses attention to relate every word to every other word, then predicts the next word.ChatGPT, machine translation
10K-means ClusteringUnsupervisedAssigns points to the nearest of k centers and moves the centers until they settle.Customer segmentation, image color compression
11Principal Component AnalysisUnsupervisedRotates the data onto a few new axes that hold the most variation.Feature reduction, face recognition
12Generative Adversarial NetworkUnsupervisedA generator makes fake samples and a discriminator tries to catch them until the fakes look real.Image synthesis, image super-resolution
